# Bedroomrulette / Random Sex Positions

Private Vite + React prototype for a consent-first couples game. The current build uses a playful reveal interaction with position cards, intensity filtering, manual/auto modes, sound toggle, sharing actions, and static legal/SEO routes.

## Status

- Core app source lives in `src/`.
- Static assets live in `public/positions/` and `public/voice/`.
- Design explorations live in `concepts/`.
- Recent direction moved away from Magic 8 Ball trade dress toward `bedroomrulette` and heart/reveal concepts. Some metadata and URLs still retain the original `magicsexball.com` / `Random Sex Positions` wording and should be cleaned up before public relaunch.
