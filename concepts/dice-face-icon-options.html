Dice face visual directions

Icon set options

These are visual directions for the non-text dice faces. Pick one direction, mix icons between rows, or reject all of them before implementation.

A. Romantic table

Closest to the current mood: wine, coupe, toast, heart, sparkle, lips. Clear, soft, and not too noisy.

B. After-dark lounge

More night-out and flirt-game: toast, martini coupe, crescent, mask, spark, heart.

C. Luxe minimal

Less literal, more premium object language: wine, gold coupe, room key, moon, sparkle, heart.

D. Playful flirty

More toy-like and funny: toast, lips/heart, rose, sparkle, moon, coupe. Good if the dice should feel less formal.
